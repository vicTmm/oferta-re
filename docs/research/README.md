# Pesquisa de produto — Oferta Re

A apresentação `2026-10-15-apresentacao.html` é um arquivo independente, sem dependências externas. Contém filtros por prioridade e área, pesquisa sem distinção de acentos, detalhes de cada lacuna, fontes e roteiro de validação. É possível abrir o HTML diretamente no navegador.

Para navegar também para os relatórios a partir da apresentação, execute na raiz do repositório:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory docs/research
```

Abra http://localhost:4173/2026-10-15-apresentacao.html.

## Proveniência

- Pesquisa: Gemini 3.8 Flash (High), no Antigravity CLI (`agy`), em sessão do projeto no Orca.
- O usuário autorizou seguir com a pesquisa web do `agy`, sem o modo oficial Gemini Deep Research, que não estava disponível nessa sessão.
- Relatório e dados originais: `2026-10-15-lacunas-gemini.md` e `.json`.
- Apresentação e revisão: Codex; a apresentação embute uma cópia dos dados e adapta rótulos para leitura. O relatório original permanece disponível para conferir os detalhes.
- Escopo: código e documentação do checkout e fontes públicas. Sem consulta a contas, arquivos ou dados privados de clientes.
- Prioridades e horizontes de 30/60/90 dias são hipóteses para planejamento, não orçamento, compromisso de prazo ou parecer regulatório.

As recomendações não implementam funcionalidades nem alteram o banco. Fontes e limitações estão no relatório e na apresentação. Um link acessível, isoladamente, não comprova a validade de uma conclusão: considere o escopo e a data de cada referência.
